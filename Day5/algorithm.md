# Algorithm

# Bubble Sort
1.Read size of array.<br>
2.Read array elements.<br>
3.Print before sorting array elements.<br>
4.Call function insertion_sort()<br>
    i]Repeat from i=0 to size-2.<br>
    ii]Compare each adjacent pair of elements from index 0 to size-i-2.<br>
    iii]If the left element is greater than the right element,swap them.<br>
    iv]After each pass, the largest element reaches its correct position.<br>
    v]Repeat until all passes are completed.<br>
    vi]Display the total number of passes and comparisons performed.<br>
5.Print After Sorting array elements. <br>
6.Return 0.<br>
7.Stop<br>


# Insertion Sort
1.Read size of array.<br>
2.Read array elements.<br>
3.Print before sorting array elements<br>
4.Call function insertion_sort()<br>
    i]consider the first element as already sorted.Start from the second element.<br>
    ii]Store the current element in a temporary variable (key).<br>
    iii]Compare the key with the element from right to left.<br>
    iv]Shift the larger element one position to the right.<br>
    v]Insert the key at its correct position.<br>
    vi]Display the total number of passes and comparisons performed.<br>
5.Print After Sorting array elements. <br>
6.Return 0.<br>
7.Stop<br>


# Selection Sort
1.Read size of array.<br>
2.Read array elements.<br>
3.Print before sorting array elements.<br>
4.Call function selection_sort()<br>
    i]Repeat from i=0 to size-2<br>
    ii]Compare arr[i] with every element from i+1 to size-1.<br>
    iii]If arr[j] is smaller than arr[i],immediately swap arr[i] and arr[j].<br>
    iv]Repeat until all passes are completed.<br>
    v]Display the total number of passes and comparisons performed.<br>
5.Print After Sorting array elements. <br>
6.Return 0.<br>
7.Stop<br>
