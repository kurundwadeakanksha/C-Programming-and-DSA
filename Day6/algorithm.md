# Stack Operations Algorithm 

1.Push(Add an item to the stack)
1]Start.
2]Check if the stack is full.
3]If full,show an error message and stop.
4]Otherwise,move the top pointer to the next position.
5]Place the new item at the top.
6]Stop.

2.Pop (Remove the top item from the stack)
1] Start.
2] Check if the stack is empty.
3] If empty, show an error message and stop.
4] Otherwise, remove the item at the top.
5] Move the top pointer to the previous position.
6] Stop.

3.Peek(View the top item without removing it)
1] Start.
2] Check if the stack is empty.
3] If empty, show an error message and stop.
4] Otherwise, return the item at the top.
5] Stop.

4.isEmpty (Check if the stack has no items)
1] Start.
2] If the top pointer is below the starting point (e.g., -1), the stack is empty.
3] Otherwise, it has items.
4] Stop.

5.isFull (Check if the stack is full)
1] Start.
2] If the top pointer is equal to the last position of the stack, the stack is full.
3] Otherwise, it is not full.
4] Stop.
