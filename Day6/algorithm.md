# Stack Operations Algorithm 

1.Push(Add an item to the stack)<br>
1]Start.<br>
2]Check if the stack is full.<br>
3]If full,show an error message and stop.<br>
4]Otherwise,move the top pointer to the next position.<br>
5]Place the new item at the top.<br>
6]Stop.<br>

2.Pop (Remove the top item from the stack)<br>
1] Start.<br>
2] Check if the stack is empty.<br>
3] If empty, show an error message and stop.<br>
4] Otherwise, remove the item at the top.<br>
5] Move the top pointer to the previous position.<br>
6] Stop.<br>

3.Peek(View the top item without removing it)<br>
1] Start.<br>
2] Check if the stack is empty.<br>
3] If empty, show an error message and stop.<br>
4] Otherwise, return the item at the top.<br>
5] Stop.<br>

4.isEmpty (Check if the stack has no items)<br>
1] Start.<br>
2] If the top pointer is below the starting point (e.g., -1), the stack is empty.<br>
3] Otherwise, it has items.<br>
4] Stop.<br>

5.isFull (Check if the stack is full)<br>
1] Start.<br>
2] If the top pointer is equal to the last position of the stack, the stack is full.<br>
3] Otherwise, it is not full.<br>
4] Stop.<br>
